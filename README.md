
# Ecosystem Simulation (GUI)

Ecosystem Simulation (GUI) — это интерактивное десктопное приложение с графическим интерфейсом на базе Java 21, созданное для визуализации и пошагового управления процессами жизнедеятельности виртуальной экосистемы.

### Основные функции

* **Графическая визуализация:** Наглядное отображение игрового поля с различимым цветовым и символьным представлением сущностей (растений, травоядных и хищников).
* **Управление потоком времени:** Возможность запуска симуляции в реальном времени, постановки на паузу и выполнения отдельных пошаговых тактов.
* **Инспекция объектов:** Получение полной информации о выбранном существе (текущий уровень энергии, координаты, статус) по клику мыши.
* **Предварительная настройка:** Отдельный интерфейс первичной конфигурации параметров мира (размеры сетки, плотность населения) перед стартом симуляции.

### Используемые механики и архитектура кода

* **Полиморфизм и метод `act()`:** Наследование от абстрактного класса `Agent`, где поведение каждого вида описывается индивидуальной реализацией логики перемещения, питания и размножения.
* **Тактовый движок `env.step()`:** Центр управления логикой симуляции, отвечающий за синхронизацию времени, смену состояний существ и пересчет населения на сетке.
* **Событийно-ориентированная модель (GUI Listeners):** Перехват действий пользователя (нажатие кнопок «Старт», «Пауза», «Шаг») для управления циклом симуляции.
* **Графический рендеринг (`repaint()`):** Автоматическая перерисовка панели `SimulationPanel` при изменении состояния среды после вызова очередного шага `env.step()`.
* **Инспекция сущностей (`env.getAgent(x, y)`):** Поиск агента по координатам клика мыши и вывод его параметров в модальном диалоговом окне `AgentInfoDialog`.
