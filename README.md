# Ecosystem Simulation (CLI)

Ecosystem Simulation (CLI) — это консольное приложение на базе Java 21, предназначенное для моделирования и анализа динамики искусственной экосистемы. Программа воспроизводит процессы взаимодействия между различными типами сущностей: растениями, травоядными и хищниками в замкнутом виртуальном пространстве.

### Основные функции

* **Моделирование жизненного цикла:** Автоматический расчет процессов питания, перемещения, размножения и естественной гибели агентов на каждом такте времени.
* **Текстовая визуализация:** Отображение текущего состояния сетки симуляции в реальном времени с использованием псевдографики и символов.
* **Конфигурирование параметров:** Гибкая настройка размеров поля, начальной численности популяций и скорости выполнения шагов.
* **Сбор и логирование данных:** Вывод текстовой статистики по численности каждой группы агентов в процессе работы программы.
* **Высокая производительность:** Минимальное потребление ресурсов за счет отсутствия графической оболочки.

### Используемые механики и архитектура кода

* **Полиморфизм и метод `act()`:** Базовый абстрактный класс `Agent` задает общий контракт. Каждая конкретная сущность (`Plant`, `Herbivore`, `Predator`) переопределяет метод `act()` со своей уникальной логикой (фотосинтез, поиск травы, охота на травоядных).
* **Тактовый движок `env.step()`:** Метод класса `Environment`, который на каждом шаге опрашивает всех агентов, вызывает их жизненный цикл, обрабатывает взаимодействия на клетках и обновляет общее состояние мира.
* **Безопасное управление списками:** Удаление погибших существ (энергия $\le 0$) и добавлений новорожденных через временные списки для исключения ошибок модификации коллекций (`ConcurrentModificationException`).
* **Инкапсуляция характеристик:** Сокрытие логики расхода энергии, координат и состояния жизни внутри отдельных объектов-агентов.
